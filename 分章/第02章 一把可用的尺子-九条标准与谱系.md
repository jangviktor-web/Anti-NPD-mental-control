# 第2章 一把可用的尺子：九条标准与"自恋"的谱系

> 所属：第一部分 认识它：先把“贴标签”的冲动放下

## 2.1 先看总纲：五条只是入场券，四个附加条件才是门槛

DSM-5 把 NPD 归入 B 类人格障碍——戏剧化、情绪化、反复无常的一群，与表演型、反社会型、边缘型同群。总纲是：从成年期早期开始（通常指近二十岁到三十岁之前），在行事作风中明显可见**自恋性幻想（或行为）、对于被阿谀赞美的渴求，以及同理心的匮乏**；界定方式是在九个要点中**符合五个以上**（依据：陈俊钦《原来这就是B型人格》第 3 章；《三联生活周刊》2026 年第 32 期同记"需满足五条以上"）。

但"五条"只是入场券。临床上还要看四个附加条件：这些行为**是否从青年时期起、是否持续数年、是否出现在工作／家庭／亲密关系等多种场景、是否反复破坏本人和周围人的生活**（依据：《三联生活周刊》2026 年第 32 期心理咨询师王秀冰）。

记忆口诀：**五条以上 + 青年期起 + 跨场景 + 持续数年 + 反复破坏生活**，缺一不可。

## 2.2 九条标准逐条：原文与日常可观察表现

| # | DSM-5 标准（要点） | 日常可观察的通俗表现 |
|---|---|---|
| 一 | "我很重要"的自恋感，夸大成就与天赋 | 把小事讲成丰功伟绩；把团队成果说成自己的；被忽略时不快 |
| 二 | 沉溺于想象中的成功、权力、显赫、美貌或理想化爱情 | 反复谈"有一天我会……"却无对应行动；对"灵魂伴侣"的执念 |
| 三 | 坚信自己特别、独一无二，只有少数伯乐能懂 | 常说"一般人不懂"；瞧不起普通同事、邻居；炫耀"高级"人脉 |
| 四 | 对赞美的渴望超过一般人 | 反复索取肯定；频繁看点赞；不获表扬即阴郁或找茬 |
| 五 | 认为自己有特权，期待别人顺从 | 要特批、让规则为自己让路；被拒即上升为"你不尊重我" |
| 六 | 掠夺性的人际关系：利用别人达成目的 | 把关系当资源网；只在需要时联系你；让你垫付而无表示 |
| 七 | 缺乏同理心，无意觉察或认同他人的情绪与需求 | 你说不好受，他立刻把话题绕回自己；你生病时最关心"谁照顾我" |
| 八 | 时常嫉妒别人，或认为别人嫉妒自己 | 见不得身边人变好；你一有进步就泼冷水；总说"他们都在眼红我" |
| 九 | 自大、傲慢的行为或态度 | 居高临下、爱用反问句；对服务人员刻薄；当众贬低他人以抬高自己 |

——依据：陈俊钦书第 3 章（逐条原文）；《三联生活周刊》2026 年第 32 期九条简述与之一致。

## 2.3 一张连续谱：健康自恋、人格倾向、人格障碍

素材给的不是"有／无"的开关，而是一条连续谱：

| 层次 | 判据 | 与"障碍"的核心差异 |
|---|---|---|
| **健康自恋 / 高自尊** | 稳定自我价值感：会在意评价、受批评会难受、失败会怀疑自己，但**不会因此推翻对自己的全部认识** | 自我价值**内部稳定**，不需外界持续供给 |
| **倾向（亚临床）** | 未达疾病程度；"人格障碍者常常为难别人，人格倾向者却容易为难自己" | 有自恋基础，但**主要在自己身上受苦** |
| **障碍** | 五条以上 + 青年期起 + 跨场景 + 持续数年 + 反复破坏生活 | 自我价值**外包给外界**，且长期损伤关系、丧失从错误中调整的能力 |

——依据：陈俊钦书第 3 章；《三联生活周刊》2026 年第 32 期Pincus："适度自恋是正常人格功能的一部分"。

对你的意义只有一句：**倾向者为难自己，障碍者为难别人**；你要防的是"是否持续损耗你"，而不是对方的标签等级（依据：本书第 20 章 Q7；《三联生活周刊》2026 年第 32 期徐钧）。

流行病学锚点决定你别把"到处都是"当成事实：NPD 发病率一般占总人口 **1%~2%**，专科医院就诊比例约 **5%**，多年几无变化；患病率中位数约 **1.6%**，不属于高发疾病。所以**网络"丰富"≠临床"稀缺"**——社交媒体上并没有"确诊增多"，只有传播层面的泛化（依据：《三联生活周刊》2026 年第 32 期李颖；十点读书《确诊NPD的人，越来越多了》；另参本书第 1 章）。

## 2.4 防止误伤：别把正常的自信当成病态

这也是最容易误伤正常自信者的地方。

| 观察点 | 病态自恋 | 健康的自尊 / 自信 |
|---|---|---|
| 自我形象 | 过度膨胀且不受自己控制——"一张放不下的老脸、一颗碰不得的玻璃心" | 现实、可调整，不必时时维护 |
| 面对挫败 | 极度崩溃，**指控别人从中作梗**，把挫败感转为怒气发泄在别人身上（或彻底逃避） | 会难受、会怀疑，但**不因此推翻对自己的全部认识** |
| 对被忽视 | 你不顺从＝**背叛**；"当他们发现别人跟自己切割得很干净时，通常会相当崩溃" | 能接受别人有独立边界 |
| 看待他人 | 他人是**确认自己的镜子** | 能看见别人是独立个体 |
| 区分窍门 | **"真正值得观察的，是他能否在不被赞美时仍保有自我价值感，能否看见别人同样独立、复杂。"** | 不靠贬低他人获得存在感 |

——依据：陈俊钦书第 3 章；《三联生活周刊》2026 年第 32 期"自恋"节。

还要分清**自我推销（技能）与自恋（长期人格特质）**：求职、升学时包装自己可以理解，甚至有用；而自恋"往往是不分场合的，而且是贯穿在你的所有社会交往之中"。真正的谦逊也不是自我贬低，而是"**一种准确看待和评估自我的能力**"（依据：《自恋时代2》；另见 本书第 20 章 Q2）。

一句话收束本章：**问题从不在"爱不爱自己"，而在"自我价值能不能内部稳定"。**

> **本章依据**：陈俊钦《原来这就是B型人格》第 3 章；《三联生活周刊》2026 年第 32 期（"自恋"节：Pincus、徐钧、李颖、王秀冰）；十点读书《确诊NPD的人，越来越多了》；《自恋时代2》；本书第 1–4 章；本书第 20 章 Q1、Q2、Q7。
