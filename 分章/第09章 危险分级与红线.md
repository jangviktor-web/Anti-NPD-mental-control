# 第9章 先判安全，再谈输赢：危险分级与红线

> 所属：第三部分 判断处境：定法才是分水岭

你要问的不是"他那句话我该怎么回"，而是"我现在安全吗"。同样一句贬低，在 L1 值得回一句边界话；在 L4，你回什么都不重要，重要的是今晚睡在哪里。

## 9.1 铁律：危险等级 > 场景 > 可退出性 > 策略偏好

顺序不可调换（依据：本工具箱《反制决策引擎》§0.3）。你更擅长哪种策略、更偏爱哪种姿态，在危险等级面前一律作废。并且：**等级由行为性质决定，不由"他态度好不好"决定**（同上 §1.2）。

## 9.2 危险四级：判据与模式切换

| 等级 | 判据信号（命中任一即入档） | 切换到什么模式 |
|---|---|---|
| **L1 安全（消耗型）** | 贬低、甩锅、抢功、要求陪吃或情绪劳动、忽冷忽热、频繁挑刺，但**无系统性剥夺**；你的损耗是"累、烦、自我怀疑" | **和解**（共处管理）：结构化沟通 + 信息饮食，辅以书面留痕 |
| **L2 警示（情绪虐待）** | 系统性煤气灯（长期否认你的现实）；负罪感与羞辱常态化；诋毁受害者；"扮演受害者"要你承担；贬低到你内化"我真不行" | **祛邪**（降接触）：灰岩法、BIFF、破除 JADE；并行启动退出准备（B 计划） |
| **L3 危险（暴力、经济控制）** | 任何肢体暴力（推搡、掌掴、掐、踢、投掷、堵门、摔砸）；破坏财物；性胁迫；**经济控制**（锁卡、断账户、以钱换条件）；以自杀／自伤要挟；跟踪、监控、查岗、翻手机、定位 | **安全 + 撤离**：启动退出计划、外部支持网、律师与机构介入；沟通不再是主战略 |
| **L4 极端（人身安全受威胁）** | 死亡威胁（你、孩子、宠物）；武器出现或提及；勒颈、殴打致伤；尾随／入室／围堵；扬言"得不到就毁掉"且已行动；分手后的报复攻击 | **只做三件事**：脱离现场 → 专业求助（警方／反家暴／律师） → 建支持网。**话术全部作废** |

依据：上司手册 1.1、5.2；Ramani 第1、3、7、8章；西蒙 第七、九章；Behary 第1、6章；三联"以爱之名""我的领导是'NPD'?""一位反NPD博主"。

## 9.3 两条判级提醒

- **升档不可逆。** 出现过暴力或经济控制，等级只升不降；"他最近态度很好"不是降档理由，那是间歇性强化（见第10章 理-2）。
- **躯体信号是最早、最诚实的仪表。** 他的（不断收紧身体、扣紧衣服）＝压力表，提示他快失控（上司手册 5.3）；你的（胃紧、失眠、心悸、茶饭不思）＝你已被消耗到什么程度（三联，何珺"长久的打压，令何珺茶饭不思"）。
- ⚠️ 反常识一条：**他的"突然不挑刺"不是好转而是危险信号**（上司手册 5.2："突然不挑刺：可能判你为敌酝酿越级告状，'沉默是宣战'"）。

## 9.4 三条狠结论：术是对的，证是错的

> "我用了灰岩法，没用。""我设了边界，他反而更暴怒。""我断联了，却被更疯狂地追打。"（素材原文）

失败的原因不是"不知道该做什么"，而是跳过判断直接出招：

- **对高危者用灰岩法 ＝ 送人质：** 面无表情会被读成蔑视，触发升级报复（Behary 第6章 perilous narcissist）。
- **对完全不可退出者用断联 ＝ 自伤：** 有共同未成年孩子、无法调岗时，"断联"落不了地，只换来更猛的追打（Ramani 第8章）。
- **在抛弃（回吸）期用共情 ＝ 自投罗网：** 回吸期的示弱不是改变，是间歇性强化（西蒙 第七章「老虎机效应」）。

记法：**相位决定剂量，等级决定方向。** 灰岩法只在贬低期与事务期有效。

## 9.5 14 条安全红线（概要）

任一条成立：**话术作废，安全是唯一目标。** 详细处置见第17章。

| # | 信号 |
|---|---|
| 1 | 以任何形式威胁你的人身安全（"我让你活不下去""你出门小心点"），含隐喻式威胁 |
| 2 | 任何肢体暴力：推搡、拉拽、掐脖、扇打、拳打脚踢、用物品投掷或击打 |
| 3 | 强迫性行为、性胁迫、以性报复相威胁 |
| 4 | 跟踪、尾随、蹲守、共享定位或软件监控、反复出现在你单位或住处 |
| 5 | 持械、展示武器、砸毁物品（砸墙、摔手机、砸家具） |
| 6 | 威胁伤害你的孩子、父母、亲友 |
| 7 | 威胁伤害宠物 |
| 8 | 以自己的自杀／自伤相要挟，以阻止你离开或逼你回应 |
| 9 | 经济封锁：没收工资、控制账户、断生活费、逼你辞职、扣押证件 |
| 10 | 限制人身自由：堵门、反锁、不让出门、扣手机、抢车钥匙 |
| 11 | 到你单位或亲友处骚扰施压（闹事、造谣、堵人） |
| 12 | 网络报复：散布隐私、性私密影像威胁、造谣、人肉、"挂人" |
| 13 | 酒精／药物下的失控，或迫使你处于无法自保的状态 |
| 14 | 你自己的直觉在说"会有危险"：心口一紧、头皮发麻、反复噩梦、听到开门声就僵住 |

依据：本工具箱《安全与危机》§4；案例见三联"以爱之名"（伍鸣就医报警）与蓝真"心口猛地一紧"。

## 9.6 红线之后：四条停止 + 三条不做

**四条停止：** 停止话术应对、"反制技巧"与"让他意识到自己的问题"；停止"我再忍一次看看"；停止单独见面、单独谈判、单独收拾东西；停止为了取证进入危险场景——**没有任何一条证据比你的安全更值钱**（本工具箱《安全与危机》§4）。

**三条不做：** **不对话**（不为"最后一次说清楚""为了孩子""好好告别"回到讲道理）；**不威胁**（不预告报警／起诉／公开，威胁只会招反扑并暴露底牌，西蒙 第十章「避免做出威胁」）；**不报复**（不用对方的手法回敬，那既违法，也让你在法律上失去有利位置——三联，学员青禾："如果我做到这个样子，我是不是也跟他是一样的了？"）。

原则四个字：**先离开，后处理。**（依据：三联"创伤"引述赫尔曼——对长期受虐待者，第一步最重要的是脱离施暴者、获得稳定的住处与经济处境。）
