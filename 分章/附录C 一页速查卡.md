# 附录C｜一页速查卡（可单独打印）

> 平时看卡①③④，出事时看卡②⑥。骨架始终是：识证 → 明理 → 定法 → 出术。

## 卡① 五条识别口径（不问"他是不是"，只问"吻合与损耗"）

1. **自我价值外包**：不赞美就阴郁、找茬；不被顺从即"你不尊重我"。
2. **共情缺席**：你说不好受，他立刻绕回自己；你的痛被定义成"你太敏感"。
3. **特权感**：规则、约定、他人的时间默认为他让路。
4. **循环相位**：理想化（蜜月）→ 贬低 → 抛弃（回吸），忽冷忽热往复。
5. **损耗判据（最关键）**：你是否长期自我怀疑、身体报警（胃紧、失眠、心悸）。**行为吻合＋你在受损耗就够了**——不必先证明他"有病"才有资格止损。

（依据：第1章 §1.4、第2章 §2.1/§2.3；陈俊钦书第3章；三联《NPD.pdf》李颖、王秀冰）

## 卡② 危险分级 L1–L4 一句话判据

| 等级 | 一句话判据 | 你该做什么 |
|---|---|---|
| **L1 安全（消耗型）** | 贬低、甩锅、挑刺、要情绪劳动，但**无系统性剥夺** | 和解：结构化沟通＋信息饮食＋留痕 |
| **L2 警示（情绪虐待）** | **系统性煤气灯**、羞辱常态化、贬低到"我真不行" | 祛邪：灰岩法、BIFF、破除 JADE，并启动退出准备 |
| **L3 危险（暴力/经济控制）** | 肢体暴力、砸物、性胁迫、**经济封锁**、监控查岗、自伤要挟 | 安全＋撤离：退出计划、律师与机构介入 |
| **L4 极端（人身受威胁）** | 死亡威胁、持械、勒颈、尾随入室、"得不到就毁掉"且已行动 | 只做三件事：脱离现场 → 专业求助 → 建支持网。**话术作废** |

（依据：第9章 §9.2；两条提醒：**升档不可逆**；"他最近态度很好"不是降档理由）

## 卡③ 三条最常用策略（L1–L2 通用）

- **策略 1｜灰岩法**：掐断供给、只走事务通道，语气平淡、信息极简。只在贬低期与事务期有效；L3/L4、脆弱型慎用。
- **策略 5｜信息饮食**：好消息先给啦啦队队长，坏消息直切正题；先建支持者名单。
- **策略 11＋12｜结构化沟通＋书面留痕**：只谈事、给选项；定稿走邮件，口头指示补确认。

（依据：第10章 §10.4.3；西蒙 第七、十章；Ramani 第7章；Behary 第7章）

## 卡④ 万能句型 6 条（照读即可）

> 说完就停，不给下一轮开口的接口。不解释、不辩论、不道歉、不上情绪。

1. 「我需要一点时间理清楚，稍后回复你。」
2. 「我明白你的意思了。这件事我心里有数，我自己会处理。」
3. 「我现在的状态不适合继续谈。我需要一点独处时间整理一下。」
4. 「我理解你会有情绪，但这不是我能替你承担的部分。」
5. 「这件事我需要先确认一下，确认后同步给你。」
6. 「这个我需要想一想，明天给你答复。」

（依据：第12章 §12.2；效果因情境而异，是低风险默认选项，不是保证）

## 卡⑤ 边界四步公式

**观察事实（不评判）→ 表达感受/需要（"我"语句）→ 提出明确请求 → 说明并执行后果**

- ① 只说**能被录像机拍到**的事实："今天吃饭时，我说话说到一半，你打断了我三次。"
- ② 说"我"的感受与需要："我会很不安，因为我需要事先知道。"
- ③ 一个具体、可执行、能答"是/否"的请求："等我把这句话说完再回应，可以吗？"
- ④ 说明"**我会怎么做**"并在触发时立刻执行："通话里出现吼叫，我就说'冷静后再谈'并挂断。"

（自查：真边界是"我＋动词"，伪边界是"你＋应该"。第④步不执行，前三步作废。依据：第11章 §11.1–§11.3；西蒙 第十章；Behary 第7章；"四步公式"命名**素材未见直接出处**）

## 卡⑥ 红线出现时的四步求助

- **① 脱离现场**：先离开，后处理。不对话、不威胁、不报复；不为取证进入危险场景——没有任何一条证据比你的安全更值钱。
- **② 立即报警/急救**：正在发生的人身危险 → **110**；受伤、流血、意识不清、服药过量 → **120**；对方正在自伤 → **120/110** 并联系其家属。
- **③ 就医验伤、保全证据**：48 小时内就医留记录（即便看不见伤痕）；拍带时间信息的伤情；保存出警/受理凭证。
- **④ 联系机构与支持网**：反家暴/妇女维权 **12338**；法律援助 **12348**；心理援助热线（号码以当地最新公示为准）；**至少告诉一个人**——孤立是操控得手的前提。
